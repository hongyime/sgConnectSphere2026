- **AC reference**: E10-S01 - Scenario 1 (Change request recorded)
- **Type**: 2 - Happy Path

#### Pre-conditions

Event "Community Meetup" has status "Confirmed"

#### Test steps

1. Log in as organiser_a@clienta.com
  2. Open event "Community Meetup"
  3. Click "Request a Change"

  5. Submit

#### Test data
