#### Pre-conditions

Registered account exists: organiser_a@clienta.com / ValidPass123. User is on the Login page

#### Test steps

3. Immediately attempt to sign in again, this time with the CORRECT password "ValidPass123" <!-- pragma: allowlist secret -->
4. Observe the response to this 6th attempt

#### Test data

Email: organiser_a@clienta.com | 5 incorrect passwords in sequence | 6th (correct) password: ValidPass123

#### Expected result

The 6th sign-in attempt is rejected even though the password is correct; the screen shows the account is locked and displays instructions for resetting the password (e.g. a "Reset Password" link) <!-- pragma: allowlist secret -->
