# Release 1 user journey

This is a navigation/business journey, not a DFD. As built, initial Safety Review is submitted by the Coordinator once ready; re-entry after reconfirmation is automatic. This differs from the broader T-82 automatic-entry target and is explicitly recorded in the discrepancy inventory. The Safety Officer approves confirmation. Registration is Event-level with selected Sessions; the coordinator records attendance after completion. Pending Jira gates are listed in the scope inventory.
