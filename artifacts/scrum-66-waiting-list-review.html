Join the waiting list

When an Event is full, an Attendee can join its waiting list, follow released-place notices, and claim a place through the existing registration flow.

Technical work pushed · human review pending

Overview

This change gives the first Attendee to complete a claim the released Event place while keeping the list at Event level.

Details and evidence

Join, leave, and claim

backend/src/modules/attendeeRegistration/service.ts validates full/open Events and serializes join and claim. A losing claim stays waitlisted; a full chosen Session follows Pending (T-98).

Place-release notices

Withdrawals and attendee deactivation notify the remaining list when an approved place opens (backend/src/modules/accessControl/deactivation.ts; E09-S05 withdrawal flow).

Attendee flow

frontend/src/features/attendee/WaitingList.tsx shows current status, join/leave actions, and the existing registration claim path. API routes are in api/attendee/events.ts.

Scope constraints

The list is Event-level. It does not show positions, promote automatically, or reserve a place; all waitlisted Attendees are told when a place is released (C-23, T-46, T-98).
