From lockfiles to public snapshots

The SBOM generator reads dependency sources, then writes two version-controlled CycloneDX inventories for readers of the public repository.

02

Why they were ignored, and why that changed

The original rule was about generated output.

The repository-wide artifacts/ rule keeps local PostPlans, renders, reports, and scratch files out of Git. When the generator was added in PR #125, the SBOMs shared that path and were intentionally left untracked. The PR chose on-demand generation to avoid generated diffs; it did not cite a privacy or security restriction.

Now the two SBOMs are version-controlled deliverables. Their component names and versions are derived from the public package lockfile and pinned Python requirements.

The secret detector flags the npm BOM's package integrity digests as high-entropy strings. Its hook skips only these generated files; it continues scanning the source manifests, lockfile, and Python requirements.
