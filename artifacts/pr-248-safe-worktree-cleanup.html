Clean disposable worktrees; preserve active work.

PR #248 changes worktree cleanup from a blanket destructive action into a safety check: ordinary cleanup removes only clean, fully pushed branches, and repository checks warn about intentional worktrees instead of failing.

01Cleanup path02Review details03Evidence and next steps
01

The cleanup decision

A worktree is removable in ordinary cleanup only when Git can verify that it has no local changes, has an upstream, and has no commits ahead of it. Uncertainty means skip.
